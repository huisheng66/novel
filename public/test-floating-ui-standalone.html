✅ 悬浮 UI 测试页面

这是一个独立测试页面，用于验证悬浮搜索框和返回顶部按钮的样式和功能。

📋 测试步骤：

  • 向下滚动超过 300px → 顶部出现悬浮搜索框
  • 向下滚动超过 500px → 右下角出现返回顶部按钮
  • 点击搜索框 → 背景变亮（聚焦效果）
  • 输入文字 → 显示"按回车搜索"提示
  • 点击返回顶部 → 平滑滚动到页面顶部

🎯 如果你能看到效果：

说明样式和 JavaScript 逻辑都是正确的！
如果主站看不到，那就是服务器缓存或浏览器缓存的问题。

💡 解决方案：

  1. 重启 Node 服务器（Ctrl+C 然后重新 node server.js）
  2. 硬刷新浏览器（Ctrl+Shift+R 或 Ctrl+F5）
  3. 清除浏览器缓存
