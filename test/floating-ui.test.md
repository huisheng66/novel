# 悬浮搜索框和返回顶部按钮测试清单

## 测试环境
- 浏览器：Chrome、Firefox、Safari
- 设备：桌面、手机、平板
- 主题：浅色、深色

## 1. 悬浮搜索框测试

### 基础功能
- [ ] 页面加载时，搜索框默认隐藏（在屏幕上方外）
- [ ] 向下滚动超过 300px 后，搜索框从顶部滑入
- [ ] 向上滚动到 300px 以内，搜索框滑出隐藏
- [ ] 搜索框居中显示在顶部

### 交互功能
- [ ] 点击搜索框，输入框获得焦点
- [ ] 输入框获得焦点时，背景变深（毛玻璃效果增强）
- [ ] 输入框失去焦点时，背景恢复
- [ ] 输入文字时，右侧显示"按回车搜索"提示
- [ ] 点击 × 按钮，清空输入框并保持焦点
- [ ] 按回车键，跳转到小说目录页

### 目录页跳转功能
- [ ] 从章节页搜索跳转到目录页，自动填充搜索词
- [ ] 自动执行搜索过滤
- [ ] 自动聚焦到搜索框
- [ ] 自动滚动到章节列表位置
- [ ] 搜索结果显示"找到 X / Y 章"

### 视觉效果
- [ ] 毛玻璃背景效果（backdrop-filter blur）
- [ ] 圆角胶囊设计（border-radius: 999px）
- [ ] 阴影效果正确显示
- [ ] 滑入/滑出动画流畅（0.32s cubic-bezier）
- [ ] 透明度渐变正确

### 深色主题
- [ ] 深色主题下，背景色为深色半透明
- [ ] 深色主题下，文字颜色为浅色
- [ ] 深色主题下，占位符文字颜色正确
- [ ] 深色主题下，× 按钮颜色正确
- [ ] 深色主题下，毛玻璃效果正常

### 响应式
- [ ] 手机端搜索框宽度自适应（max-width: calc(100vw - 2rem)）
- [ ] 输入框宽度自适应（max-width: 60vw）
- [ ] 触摸操作正常
- [ ] 移动端键盘弹起不影响搜索框位置

## 2. 返回顶部按钮测试

### 基础功能
- [ ] 页面加载时，按钮默认隐藏
- [ ] 向下滚动超过 500px 后，按钮从右下角淡入
- [ ] 向上滚动到 500px 以内，按钮淡出隐藏
- [ ] 按钮固定在右下角（right: 1.25rem, bottom: 1.25rem）

### 交互功能
- [ ] 点击按钮，页面平滑滚动到顶部
- [ ] 鼠标悬停时，背景变深
- [ ] 点击时，按钮略微缩小（scale: 0.94）
- [ ] 如果用户开启了"减少动画"偏好，滚动立即完成（无动画）

### 视觉效果
- [ ] 圆形按钮（border-radius: 999px）
- [ ] 毛玻璃背景效果
- [ ] 阴影效果正确显示
- [ ] 淡入/淡出动画流畅（0.28s cubic-bezier）
- [ ] 上箭头 SVG 图标显示正确

### 深色主题
- [ ] 深色主题下，背景色为深色半透明
- [ ] 深色主题下，图标颜色为浅色
- [ ] 深色主题下，毛玻璃效果正常

### 响应式
- [ ] 手机端按钮大小合适（2.6rem）
- [ ] 触摸操作正常
- [ ] 移动端位置固定正确

## 6. 边界情况测试

### 极端情况

- [ ] 搜索框在页面顶部时，不会被页面内容遮挡
- [ ] 返回顶部按钮不会遮挡页面关键内容

### 错误处理
- [ ] sessionStorage 不可用时，搜索功能仍正常
- [ ] JavaScript 禁用时，不影响阅读（优雅降级）
