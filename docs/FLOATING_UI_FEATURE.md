# 悬浮搜索框和返回顶部按钮功能说明

## 功能概述

在章节阅读页面新增两个悬浮 UI 元素，提升阅读体验：

1. **悬浮搜索框** - 滚动时从顶部滑入，快速跳转到目录搜索章节
2. **返回顶部按钮** - 右下角圆形按钮，一键滚动到页面顶部

## 1. 悬浮搜索框

### 触发条件
- 向下滚动超过 **300px** 后，从顶部滑入
- 向上滚动回 300px 以内，自动隐藏

### 视觉设计
- 居中显示在页面顶部（`top: 0.6rem`）
- 圆角胶囊设计（`border-radius: 999px`）
- 毛玻璃背景（`backdrop-filter: blur(14px)`）
- 浅色半透明背景（浅色主题）或深色半透明背景（深色主题）
- 聚焦时背景加深，提升可见性

### 交互流程
1. 用户在搜索框中输入关键词（章节号或标题）
2. 实时显示"按回车搜索"提示
3. 按回车键，跳转到小说目录页
4. 自动在目录页执行搜索过滤
5. 自动聚焦并滚动到章节列表

### 技术实现
- 使用 `sessionStorage` 传递搜索词（跨页面）
- `requestAnimationFrame` 优化滚动性能
- CSS 动画：`cubic-bezier(0.22, 1, 0.36, 1)` 自然缓动
- 清除按钮（×）点击后保持焦点在输入框

## 2. 返回顶部按钮

### 触发条件
- 向下滚动超过 **500px** 后，从右下角淡入
- 向上滚动回 500px 以内，自动隐藏

### 视觉设计
- 固定在右下角（`right: 1.25rem, bottom: 1.25rem`）
- 圆形按钮（直径 `2.6rem`）
- 毛玻璃背景（`backdrop-filter: blur(14px)`）
- 上箭头 SVG 图标
- 悬停时背景加深
- 点击时略微缩小（`scale: 0.94`）

### 交互行为
- 点击后，页面平滑滚动到顶部（`smooth` 滚动）
- 尊重用户的"减少动画"偏好设置（`prefers-reduced-motion`）
- 如果用户开启了减少动画，则立即滚动（无动画）

### 技术实现
- `requestAnimationFrame` 优化滚动监听
- `passive: true` 事件监听器，提升滚动性能
- 双 RAF 变量分离（搜索框和返回按钮独立）

## 深色主题适配

### 悬浮搜索框
- 背景：`rgba(30, 30, 30, 0.6)` → 聚焦时 `0.85`
- 文字：`#ddd`
- 占位符：`rgba(255, 255, 255, 0.4)`
- 清除按钮：`rgba(255, 255, 255, 0.15)` → 悬停时 `0.25`

### 返回顶部按钮
- 背景：`rgba(30, 30, 30, 0.6)` → 悬停时 `0.85`
- 图标：`#ddd`

## 性能优化

1. **滚动监听优化**
   - 使用 `requestAnimationFrame` 节流
   - `passive: true` 监听器，不阻塞滚动
   - 两个独立的 RAF 变量，避免冲突

2. **动画性能**
   - 使用 `transform` 和 `opacity`（触发 GPU 加速）
   - 避免使用 `top/bottom/left/right` 动画
   - CSS `transition` 替代 JavaScript 动画

3. **状态管理**
   - 使用布尔变量缓存显示状态（`searchShown`, `backShown`）
   - 避免重复 DOM 操作

## 辅助功能（Accessibility）

1. **键盘导航**
   - Tab 键可聚焦到搜索框和按钮
   - Enter 键提交搜索
   - 清除按钮后保持焦点

2. **屏幕阅读器**
   - 搜索框有隐藏的 `<label>`（`position: absolute` + `clip`）
   - 清除按钮有 `aria-label="清除搜索"`
   - 返回顶部按钮有 `aria-label="返回顶部"`
   - 搜索提示有 `role="status"` 和 `aria-live="polite"`

3. **用户偏好**
   - 尊重 `prefers-reduced-motion`（减少动画）
   - 支持系统颜色方案（浅色/深色）

## 用户体验提升

### 问题解决
1. **之前**：在长章节中阅读时，想搜索其他章节需要滚动到顶部点击"返回目录"
2. **现在**：任何位置出现悬浮搜索框，直接输入关键词跳转

### 场景示例
- 用户读到第 50 章，想跳回第 10 章查看某个伏笔
- 不需要滚动回顶部 → 点击悬浮搜索框 → 输入"10" → 回车 → 自动跳转到目录并定位到第 10 章

### 额外好处
- 减少页面跳转次数（直接搜索，不需要先回目录再搜索）
- 保持阅读沉浸感（悬浮 UI 不遮挡正文）
- 深色模式友好（独立的深色主题样式）
